# 扩展中文字库指南

## 📋 需要添加的汉字列表

贪吃蛇游戏需要以下汉字（当前字库中缺失）：

```
历 史 记 录 总 局 开 始 退 出 暂 停
```

## 🛠️ 方法一：使用在线工具（推荐）

### 1. 访问在线字库生成器
https://lvgl.100ask.net/master/get-started/font.html

### 2. 配置参数
- 字体大小：32
- 字符集：将上述汉字粘贴进去
- 输出格式：C数组
- 位深度：1 bpp（单色）

### 3. 生成并下载
点击生成，会得到类似的C数组数据

### 4. 添加到现有字库
将生成的数据追加到 `chinese_32.h` 文件末尾（在最后的 `};` 之前）


## 🛠️ 方法二：使用 lcd-image-converter

### 1. 下载工具
- Windows: https://github.com/riuson/lcd-image-converter/releases
- 下载最新版 `.exe` 文件

### 2. 创建新字体项目
1. 打开 lcd-image-converter
2. File → New → Font
3. 选择中文字体（如微软雅黑、宋体）
4. 设置大小为 32

### 3. 添加字符
1. 在字符输入框输入：`历史记录总局开始退出暂停`
2. 点击 "Add" 添加这些字符

### 4. 配置输出
- Options → Conversion
- Preset: Color R5G6B5 (16-bit)
- 确保格式与现有字库一致

### 5. 导出
- File → Export
- 选择 C array 格式
- 保存为 `chinese_32_ext.h`

### 6. 合并到现有字库
复制生成的数据，追加到 `src/ControllerSystem/chinese_32.h`


## 🎯 方法三：简化方案（临时替代）

如果工具使用困难，可以继续使用**中英混合显示**：

```cpp
// 中文核心词汇 + 英文辅助
"贪吃蛇"       // 标题
"记录"         // 替代"历史记录"  
"游戏"         // 替代"总局数"
"Press O"      // 替代"开始"
"Press X"      // 替代"退出"
"PAUSED"       // 替代"暂停"
```

这是当前已实现的方案，虽不完美但实用。


## 📝 注意事项

1. **字体文件**：需要系统中有中文字体（Windows自带微软雅黑）
2. **文件大小**：每个汉字约200-400字节，12个字约3-5KB
3. **内存影响**：ESP32-S3内存足够，无需担心
4. **测试**：添加后务必编译测试
